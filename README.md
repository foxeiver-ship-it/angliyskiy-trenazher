# Тренажёр к вступительному экзамену в магистратуру по английскому языку

Одностраничное веб-приложение без зависимостей: открывается двойным щелчком по
`trenazher.html`, работает офлайн, ничего никуда не отправляет. Прогресс
хранится в localStorage браузера, поэтому вкладку можно закрыть и вернуться.

## Что внутри

**39 вопросов** из двух тестов вступительного испытания, каждый с трёхблочным
разбором.

> **Откуда правильные ответы.** На сохранённых страницах Moodle отметки
> верного варианта нет. Все ключи восстановлены при разборе и затем проверены
> тремя независимыми агентами, которые не видели ответов друг друга:
> расхождений не было ни в одном из 39 вопросов. Это значит, что ответ в
> тренажёре — обоснованный, но не официальный. Вопросы, где формулировка
> допускает спор, перечислены в `разбор/спорные-ключи.md` проекта-источника.

| № | Тема | Вопросов |
|---|---|---|
| 1 | Времена и согласование времён | 1 |
| 2 | Условные предложения и модальные глаголы | 2 |
| 3 | Инфинитив, герундий и управление глагола | 4 |
| 4 | Косвенная речь, придаточные и порядок слов | 3 |
| 5 | Местоимения, определители, артикли | 4 |
| 6 | Степени сравнения и наречия | 2 |
| 7 | Словообразование и паронимы | 5 |
| 8 | Лексика и устойчивые сочетания | 10 |
| 9 | Соответствие: дефиниции понятий | 8 |

Типы заданий те же, что на экзамене: один ответ (31) и соответствие (8).
В заданиях на соответствие четыре понятия разносятся по шести определениям,
поэтому два определения всегда остаются без пары — так задание устроено в
самом Moodle.

## Разбор после ответа

У каждого вопроса три блока, а не один «правильный ответ»:

- **Почему так** — какое правило работает и почему подходит именно эта форма
- **Почему остальные не подходят** — по каждому неверному варианту отдельно,
  на какой подмене он построен
- **Как запомнить** — короткая зацепка или мнемоника

## Режимы

1. **Тренировка по темам** — все вопросы одной темы подряд, разбор сразу после
   ответа
2. **Вариант экзамена** — 20 вопросов из разных тем, проверка в конце
3. **Работа над ошибками** — накопленные промахи; вопрос уходит из списка,
   только когда ответите верно
4. **Весь банк вперемешку**

Тренажёр помнит готовность по каждой теме, список ошибок и незаконченную
попытку: вышли посреди варианта — на главной появится карточка «продолжить».

## Структура репозитория

```
trenazher.html            собранный файл — открывать этот
index.html                редирект на тренажёр
trainer/
  собрать.py              склейка trenazher.html из частей build/
  собрать-банк.py         генерация банка из базы вопросов
  проверить.py            структурная проверка банка перед сборкой
  build/
    01-стили.html
    02-разметка.html
    банк.js               данные: window.ТЕМЫ и window.БАНК
    03-логика-данные.html  хранилище прогресса, проверка ответов
    04-логика-главная.html режимы, выбор темы, карта готовности
    05-логика-вопрос.html  отрисовка вопроса, ввод ответа, таймер
    06-логика-разбор.html  разбор и экран результата
    СПЕЦИФИКАЦИЯ.md        формат данных банка
```

`trenazher.html` **генерируется** — правки вносятся в `build/`, затем:

```bash
python3 trainer/собрать-банк.py   # если менялись база или разборы
python3 trainer/проверить.py      # структурная проверка банка
python3 trainer/собрать.py        # пересборка trenazher.html
```

Исходники банка (скриншоты попыток, тексты разборов, протокол сверки) лежат в
отдельном закрытом проекте `Экзамен-английский`; сюда попадает только
собранный `банк.js`.

## Чего пока нет

Банк неполный: нет скриншотов вопросов 6, 10, 13, 15, 18 первого теста и
18, 20, 21, 24, 25 второго. Вопрос 23 второго теста снят с обрезанным списком
вариантов и потому не заносился. По мере появления снимков банк дополняется.

## Статус

Учебный проект для личной подготовки, не является официальным материалом вуза.
