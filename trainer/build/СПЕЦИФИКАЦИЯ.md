# Формат данных тренажёра

Файл `банк.js` генерируется скриптом из базы вопросов и объявляет две глобальные
переменные. Приложение не делает сетевых запросов и работает по `file://`.

```js
window.ТЕМЫ = [
  {n: 0, название: "Времена и согласование времён"},
  ...9 тем, n от 0 до 8
];

window.БАНК = [
  {
    id: "en-0001",     // строка, уникальна
    t: 0,              // номер темы
    ty: "one",         // "one" | "many" | "short" | "match" | "gaps"
    q: "текст вопроса",
    qru: "русский перевод условия",       // если совпал с q, подстрочник не рисуется
    o: ["вариант 0", "вариант 1", ...],   // только для one/many, иначе []
    oru: ["перевод варианта 0", ...],     // длина = длине o, иначе []
    a: [0],                                // индексы верных, только для one/many
    pairs: [{l: "строка слева", r: "верный вариант справа"}],  // только match
    pairsru: ["перевод строки слева", ...],   // длина = длине pairs, иначе []
    pool: ["все варианты правого столбца"],                     // только match
    poolru: {"понятие": "перевод"},        // ключи = элементы pool, иначе {}
    ans: "эталонный ответ",                // только short
    img: "data:image/... или null",        // график в условии, base64
    oimg: ["data:image/... или null", ...], // графики в вариантах, длина = длине o
    e: "почему так",
    w: ["", "почему неверен вариант 1", ...],  // длина = длине o; [] у short/match
    k: "как запомнить"
  }
];
```

Проверка ответа:
- `one` — выбран ровно один вариант, его индекс есть в `a`;
- `many` — множество выбранных совпадает с `a` целиком (всё или ничего);
- `short` — сравнение с `ans` без учёта регистра, ё/е, пробелов по краям и
  знаков препинания; засчитывать и вариант, где ответ отличается только
  окончанием прилагательного (например «нормальная» и «нормальную»);
- `match` — каждой строке `l` сопоставлен верный `r`; засчитывается целиком;
- `gaps` — то же устройство, что у `match`: строка на каждый пропуск, общий
  `pool` словосочетаний, засчитывается целиком.

Поля `qru`, `oru`, `pairsru`, `poolru` берутся из `разбор/переводы.json`
проекта-источника и рисуются приглушённой строкой под английским текстом.

## Демоверсия

Файл `демо.js` собирается скриптом `собрать-демо.py` и объявляет
`window.ДЕМО` — массив той же формы, что `window.БАНК`, плюс поле `блок`
(«I. Лексика», «II. Грамматика», «III. Соответствие», «IV. Текст с
пропусками»), которое рисуется отдельной плашкой в шапке вопроса.

Эти задания попадают в `ПО_ID` наравне с банком, поэтому работают разбор,
список ошибок и продолжение попытки, но в `БАНК` их нет — значит они не
подмешиваются в темы, вариант экзамена и режим «весь банк».

У `gaps` в `q` лежит текст целиком с пропусками вида `... (1) ...`, переносы
строк значимы: они рисуются как есть (`white-space: pre-wrap`). В `pairs[j].l`
стоит только номер пропуска, `pairsru` там пустые строки.
